# Misi Penyelamatan di Labirin Ajaib

Game edukasi untuk anak usia 4-5 tahun, berbahasa dan bersuara Indonesia.

File:
- index.html : kerangka halaman (harus berada paling luar di GitHub)
- style.css  : warna dan tampilan
- game.js    : cara kerja game, soal, dan suara

Coba di komputer: klik dua kali index.html.
Deploy: upload ketiga file ke GitHub, lalu Import di Vercel (Deploy tanpa mengubah pengaturan).
Ubah soal/suara: buka game.js, cari "Bank soal" dan fungsi say('...').
